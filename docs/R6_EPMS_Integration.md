# CPMS → EPMS tenant billing link (V7.9 r6)

Rental office F02–F08, two companies per floor (14 tenancies, R9 design). The CPMS station `ALT_CP_Ref_V7_9` measures and
prepares the billing data; the EPMS station `ALT_EPMS_DC01` owns the tariffs, the history and the invoices.

## 1. Data prepared by the CPMS station (`tools/v79_r6.py` → `Metering/EPMS/<tenant>`)

| Point | Meaning |
|---|---|
| `PM_<T>_kWh` | tenant feeder energy register (revenue-grade sub-meter, field AI) |
| `PM_<T>_kW` | tenant feeder power |
| `EPMS_<T>_PeriodStart_kWh` | register latched at the last billing close (`EPMS_PeriodClose`) |
| `EPMS_<T>_Period_kWh` | electric energy of the current period (never negative) |
| `EPMS_<T>_QualityOK` / `EPMS_<T>_MeterResetAlarm` | register below the period start = meter reset / rollover → **billing hold** (Critical alarm), no estimate |
| `EPMS_<T>_AirShare` | tenant share of the floor VAV airflow (0–1) |
| `EPMS_<T>_Thermal_kW` / `_Thermal_kWh` / `_PeriodThermal_kWh` | airflow-weighted share of the floor BTU meter, cumulative register (integrated every minute) and period energy |
| `EPMS_<T>_ThermalBillable` | true only when `EPMS_TenantThermalBilling` = Enabled (contract) and quality is good |

Common: `Metering/EPMS/Common/EPMS_PeriodClose` (pulse, written by the EPMS or an operator at the billing close),
`EPMS_ResetTolKWh` (reset detection tolerance), `Metering/Floors/Common/EPMS_TenantThermalBilling` (default **Disabled**:
the floor AHU coil is shared, so tenant cooling is an allocation, not a measurement - enable only with an approved allocation
method in the lease).

The full list with CPMS slot, EPMS slot and `epms:key` is `registers/EPMS_RENTAL_EXPORT.csv` (generated by
`tools/gen_billing79.py`, 10 values × 14 tenants).

## 2. Link in the EPMS station (Workbench, site engineer)

Not done in this repository - it needs the site network and accounts, which are never stored here.
1. EPMS station → `Drivers/NiagaraNetwork` → add the CPMS station (FOXS 4927 as configured on the CPMS station; use a dedicated
   read-only user / role on the CPMS station).
2. `Points` → Discover → import the points of `registers/EPMS_RENTAL_EXPORT.csv` (column `cpms_slot`) into
   `/EPMS/Meters/RentalOffice/<T>/` with the names of column `epms_slot`.
3. Add the `epms:key` string slot (column `epms_key`) to each proxy point, like the existing EPMS meters.
4. History: interval history (15 min) on `PM_<T>_kWh` and `EPMS_<T>_Thermal_kWh` for time-of-use splitting and audit.
5. Billing close: an EPMS schedule / operator writes `EPMS_PeriodClose` = true (pulse) on the CPMS station at the period end,
   after the closing readings were stored in the EPMS history.
6. Copy `station/shared/web/ALT_V79_TenantBilling.html` to the EPMS station `shared/web` if the page should run there: it reads the
   proxy points under `/EPMS/Meters/RentalOffice` and the tariff points `EPMS/Tariff/Rate_OnPeak`, `Rate_OffPeak`, `Rate_Ft`,
   `Service_Charge`, `VAT_pct` automatically.

## 3. Tenant billing page (`ALT_V79_TenantBilling.html` / `.px`)

- Served by the CPMS station → LIVE from `Metering/EPMS`; served by the EPMS station → LIVE from the RentalOffice proxies and the
  EPMS tariff; opened as a file → DEMO (example values, marked "never invoice from these").
- Electricity = period kWh × (on-peak rate × on-peak share + off-peak rate × (1 − share) + Ft); cooling only when billable;
  + service charge; + VAT. Tenants on hold show no amount.
- Export CSV / JSON in the R9 EPMS interface schema (meterId, tenantId, floor, boundary, timestamp, periodStart, periodEnd,
  energyImport_kWh, thermalEnergy_kWh, quality, resetCounter, calibrationId, tariffVersion).
- Read-only: the page never writes to a station.
